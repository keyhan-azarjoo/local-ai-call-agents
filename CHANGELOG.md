# Changelog

## 0.9.0 (October 2026)

- **Phone:** real calls through a Twilio number, with no router changes (a call bridge registers this computer). Several calls at once, with the AI model, speech recognition and voices running in parallel, sized by one setting.
- **Agents:** a team per business: receptionist, specialists, real people. Hand-overs with hold music and each agent's own voice; misheard names still reach the right person. The call flow canvas has zoom, fit, tidy-up and search.
- **Business apps:** eleven professional templates and an AI builder. Each has a website, a manager page (dashboard, sortable tables, order board, calendars, customers) and MCP tools for the AI.
- **Live view:** every call word by word as it happens, recent conversations, optional recording.
- **AI engines:** a built-in llama.cpp engine with model downloads, Ollama, any OpenAI-compatible server (vLLM, LM Studio, MLX…), and cloud providers.
- **Security:** callers only reach their own bookings (number and name), tool keys, PIN lockout, cross-site protection, personal data never public, calls only through the bridge. 176 spoken security tests.
- **Testing:** 2,143 spoken test scenarios run inside the app, with published results.
