# LocalAILine app

The Flutter app: the desktop host (macOS today) and the phone companion (iOS, Android).
For what it does and how to use it, see the [main README](../README.md) and the [guides](../docs/guides/).

```bash
flutter pub get
flutter run -d macos                 # run
flutter build macos --release        # build
flutter analyze                      # static checks
flutter test $(ls test/*_test.dart test/scenarios/*_test.dart | grep -v live_test)   # tests
```

| Folder | |
|---|---|
| `lib/state/` | App state, the call-turn pipeline, the spoken test-call runner |
| `lib/services/` | Voice engine, phone (Twilio), AI engines, MCP, knowledge, business apps, companion |
| `lib/ui/` | Pages and widgets |
| `assets/engine/` | The Python voice agent, the speech lab, the Go call bridge, the LiveKit SIP patch |
| `assets/scenarios/` | The 2,143 spoken test scenarios (generated by `test/scenarios/generate.py`) |
| `test/` | Unit, widget and security tests; `*_live_test.dart` need the engines running |
| `tools/` | A latency probe for the voice agent |

See [ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how the parts fit together.
