# Screenshots

Made by `app/tool/screenshots.sh` with demo data only: a temporary database, the owner Keyhan Azarjoo,
the fictional restaurant Trattoria Bella (and other fictional businesses for the website templates),
fictional callers and UK drama numbers (07700 900xxx, 020 7946 0xxx). The desktop pictures have
"Show all features" on, so the tabs inside My assistant, Phone line and Settings show.
